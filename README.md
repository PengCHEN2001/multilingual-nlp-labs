# M2 Multilingual NLP & Machine Translation Labs

This repository is used to document the lab assignments and experiments completed for the **Multilingual NLP & Machine Translatio** course in the **M2 Computational Linguistics** program at **Université Paris Cité** during the 2026–2027 academic year.

It contains my implementations, experimental results, and notes for the different labs of the course.

## Structure
Each lab is stored in a separate folder:
```text
.
├── lab1/
├── lab2/
├── lab3/
└── ...
```

1. Lab 1 — Tokenisation across languages: explores differences in mBERT’s WordPiece tokenisation across languages, especially whether lower-resource languages tend to be split into more subword tokens.
2. Lab 2 — Multilingual representation geometry: investigates whether different languages occupy separate subspaces in mBERT, using language probing, centring, cross-lingual retrieval, principal-subspace overlap, and cross-lingual transfer.
